# Course Catalog — Lab 2

## Advanced Web Technologies

This project extends Lab 1 with styling using Tailwind CSS and shadcn/ui.

### Implemented

- shadcn/ui `Card` and `Button`
- `CourseCard` rewritten with `Card`, `CardHeader`, `CardTitle`, `CardContent`, and `Button`
- responsive course grid: 1 / 2 / 3 / 4 columns
- styled navigation with spacing, border and hover states
- hover effects on course cards
- responsive layout for phone, tablet and desktop
- `CourseCard` remains a Server Component
- existing Lab 1 dynamic routes and `LikeButton` preserved

## Run

```bash
npm install
npm run dev
```

For production verification:

```bash
npm run build
```
